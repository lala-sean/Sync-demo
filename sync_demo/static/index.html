What is being fitted?

The constrained model jointly compares 24 orthogonal signed-axis pairs, then selects the pair with the lowest fitting RMS. For every candidate it optimizes one fixed 6-DoF camera extrinsic and one shared jaw length. Jaw-root correction is zero by default; it can instead be supplied manually or added as one fixed 3D vector shared by all frames.

Exploratory visual registration — not a validated hand-eye calibration or a transform for robot control. A good image fit does not establish physical accuracy.
